# PROJECT_CONTEXT.md

## 项目总背景

用户正在打造“仓城少城主”文旅 IP。

该 IP 是上海松江仓城历史文化风貌区的人格化流量入口，目标是通过个人 IP、短视频、直播、线下门店体验、私域转化，把仓城、本草园和豆叔品牌串联起来。

## 仓城背景

仓城位于上海松江，具有老街、河道、老宅、漕运文化、松江老城记忆等标签。

目前问题：
- 认知度不高
- 人流不足
- 交通不算便利
- 需要新的内容表达和年轻化入口

## 本草园背景

本草园是豆叔品牌战略升级的生态体验园，位于上海市松江区仓城历史文化风貌区中山西路138号。

前身为王子彝先生故居/王氏宅，后由“未觉书屋”运营，现在由豆叔品牌改造为以中国传统食养文化为核心的文化体验空间。

本草园的内容卖点：
- 百年老宅
- 食养文化
- 茶饮体验
- 女性放空
- 带妈妈/父母体验
- 视频号银发经济
- 小红书女性经济
- 私域预约转化

## 五谷食养茶饮零售店背景

除本草园外，用户还负责一家五谷食养茶饮零售店的信息流视频拍摄剪辑。

该店的内容卖点不同于本草园：
- 日常饮品
- 五谷食养
- 茶饮零售
- 产品陈列
- 礼盒/伴手礼
- 给爸妈买
- 上班族轻养生
- 到店购买
